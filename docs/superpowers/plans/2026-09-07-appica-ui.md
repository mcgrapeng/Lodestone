# Plan C:UI 回归 Appica 默认视觉 + 左侧分类侧边栏 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 前端视觉回归 @appica/ui-react 默认 token 体系(monochrome),重做 logo,分类导航从横向滚动条改为左侧侧边栏(窄屏折叠 Select)。

**Architecture:** 先清 token(删自定义渐变/彩色 accent)再改布局;每个视觉任务独立 build + Playwright 截图验证;`frontend/` 内闭环,与后端零耦合。

**Tech Stack:** React 19 + Tailwind v4 + @appica/ui-react ^1.1.0 + @appica/icons-react ^1.0.0。

**Spec:** `docs/superpowers/specs/2026-09-07-arch-install-ui-design.md`(C 节)

## Global Constraints

- 颜色只允许 appica token 类(`primary`/`secondary`/`success`/`background*`/`foreground*`/`border-*`);**禁止**新写 hex/rgba/oklch 字面量(`success` 语义徽标除外——也必须用 token 类)。
- 删除符号:`gradient-text` 类、`categoryAccent` 的彩色用法、body radial 渐变背景、`mask-fade-x` 横滚遮罩。
- 分类导航不得再出现 `overflow-x-auto` 横向滚动条。
- 每任务 `cd frontend && npm run build` 通过(tsc --noEmit + vite build)。
- Playwright 验证统一走 `http://127.0.0.1:8765/`(构建产物;build 后 8765 自动服务新产物,无需重启)。

- [ ] **Step 1: 重写 CategoryBrowser 布局骨架**(确定可行的 aside 版):

```tsx

  <div className="mx-auto flex max-w-7xl gap-6">
    {/* ≥lg:左侧分类栏 */}
    <aside className="hidden w-56 shrink-0 lg:block">
      <nav className="sticky top-[140px] flex max-h-[calc(100vh-160px)] flex-col gap-0.5 overflow-y-auto pr-1">
        {categories.map((c) => {
          const on = c.id === currentId
          return (
            <button
              key={c.id}
              type="button"
              onClick={() => onSelect(c.id)}
              aria-current={on ? 'true' : undefined}
```

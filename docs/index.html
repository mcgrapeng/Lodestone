⚡ Lodestone

每天 5 分钟，给 AI 工程师一份"现在值得关注"清单。

Lodestone（磁石）= 古代航海家用天然磁铁矿导航。我们把 GitHub、HuggingFace、MCP Registry、arXiv 四个数据洋流汇成一张中文友好的仪表盘——按 20 个用途分类，不刷十几个 RSS。

🧭 一图流：数据怎么流

            4 数据洋流                        4 级爬虫兜底
                                                  ┌─ httpx ─── 多数直接命中
  GitHub   ──┐                                  ├─ cloudscraper ── 破 Cloudflare
  HuggingFace ─┼─→ 抓 · 去重 · AI 过滤 ──→ 仪表盘 ──┤
  MCP Reg    ─┤                                  ├─ playwright_stealth ── 真浏览器
  arXiv      ─┘                                  └─ jina ── 本地 IP 被封换出口
                  ↓
              Postgres（推荐）/ JSON 回退
                  ↓
              ┌─ 卡片墙：hot_now / trending / 分类 / 24h 星增
              ├─ 5 桶详情：是什么 / 能干什么 / 解决什么问题 / 同类 / 何时选它
              └─ 一键装为 skill（仓库根有 SKILL.md 时）

GitHub 抗爬时其他 3 个源照常工作——你不会"今天啥都看不到"。

📦 技术栈

  • 后端：Python 3.10+（stdlib + 可选 pg8000）
  • 数据库：PostgreSQL（JSON 回退）
  • 爬虫：4 引擎分级 fallback，stdlib + 可选依赖
  • 数据源：5 个互补源（GitHub + HF × 2 + MCP + arXiv）
  • 前端：React 19 + Vite 6 + Appica UI + Tailwind v4
  • 依赖：gh CLI 已认证；翻译走 Google Translate；可选 LLM 走 Claude / OpenAI / Ollama

🚀 部署

# .env
RADAR_HOST=0.0.0.0          # serve 监听外部接口（前面挂 nginx 做 TLS）
LODESTONE_HOME=/var/lib/lodestone  # 数据缓存目录（多用户服务器场景）
PGHOST=10.0.0.5             # PG 不在 localhost 时

🚀 部署到服务器

本地能跑 ≠ 服务器能跑。下面 3 件事必须改，否则会在 Linux 服务器上炸。

1. .env 配 Postgres（推荐）

cp .env.example .env
# 编辑 .env，把 PGHOST/PGUSER/PGPASSWORD/PGDATABASE 改成服务器实际值

.env 里的所有变量在每个 radar.py 命令开头自动加载。Shell 环境变量优先级更高。

2. 让 serve 监听外部接口

默认 serve 只绑 127.0.0.1（安全：API 能 git clone 到你机器的 skill 目录，不暴露到内网）。

服务器需要别人访问时：

# .env 里加
RADAR_HOST=0.0.0.0

# 同时强烈建议前面挂 nginx / caddy 做 TLS + 鉴权

3. Skill 缓存重定向到项目目录

默认 skill 缓存写 $HOME/.cache/lodestone/，多用户服务器需要重定向：

# .env 里加
LODESTONE_HOME=/var/lib/lodestone
mkdir -p /var/lib/lodestone

数据库 schema（repos / repo_categories / repo_stars_history / crawl_log）由 db.ensure_schema() 在第一次 crawl 时自动建。装好 .env + PG 可达，直接 ./radar.py crawl 就行。

⚡ 命令速查

命令 干什么 何时用
./radar.py web [port] 一键：起 serve + 自动开浏览器 日常看仪表盘（推荐）

./radar.py audit 数据质量审计（去重 / 金融过滤 / 来源分布） 月度自查

🔌 API 端点（serve 在跑时）

方法 路径 返回
GET /api/data {hot_now, categories, fetched_at} 主视图
GET /api/local 本机已装的 skills / commands / agents / plugins
GET /api/top?page=&size=&sort= 1k+ AI 主流项目池（按 stars/recent/name 排序）
GET /api/gain?size=&min_delta= 24h 星增榜
GET /api/stats 语言 × 主题分布
GET /api/scrapers/status 当前可用爬虫引擎
POST /api/crawl 后台触发 crawl（忙时返 409）
POST /api/install 克隆 GitHub repo 装为 skill
POST /api/install-cli 把任意 CLI 包成 slash command

所有 API 只绑 127.0.0.1 —— 因为能 git clone 到你机器的 skill 目录，暴露到内网等于送权限。需要 LAN 访问：RADAR_HOST=0.0.0.0 加进 .env，外面套 nginx。

🕷 数据怎么走（爬取流程）

./radar.py crawl
   │
   ├─[1] 文件锁（data/crawl.lock）—— 防并发
   │
   ├─[2] GitHub GraphQL 批量搜索（204 个 query × N aliases/请求）
   │      失败 → REST gh_search → HTML 阶梯兜底
   │
   ├─[3] 4 个非 GitHub 数据源并行抓：
   │      HF Spaces · HF Models · MCP Registry · arXiv
   │
   ├─[4] AI 过滤（topic + 描述关键词 + 金融屏蔽）
   │
   ├─[5] 去重（按规范化 git URL）
   │
   ├─[6] SKILL.md 探测 —— 标记哪些 repo 能装为 skill
   │
   ├─[7] 翻译（Google Translate 免费端点，per-repo 持久缓存）
   │
   ├─[8] 结构化摘要（README → 介绍 / 能干什么 / 优势 三段）
   │
   ├─[9] LLM 5 维度决策分析（可选，需配 ANTHROPIC_API_KEY 等）
   │      是什么 · 解决什么问题 · 同类项目 · 优缺点 · 何时选它
   │
   └─[10] 入库 —— Postgres 优先；失败/不可达时回退 data/latest.json

整个流程 ~3-5 分钟。文件锁保证两个 crawl 不会撞车。

🧾 卡片显示什么

每张卡片字段：

字段 含义
name / url 仓库 owner/repo + GitHub 链接
summary_zh 中文一句话介绍
summary_sections 详细介绍（介绍 / 能干什么 / 优势，README 拆分）
analysis_5d LLM 5 维度决策（需要配 LLM API key）
stars / forks / lang / topics GitHub 元数据

⚠️ 不是所有 GitHub 仓库都能装为 skill —— 只有仓库根或 /skills/ 目录下有 SKILL.md / skill.md / SKILL.yaml 的才算。LLM 框架、IDE 插件、模型权重等都不是可装载的 skill 格式，装按钮会隐藏，并在卡片里说明原因。

🕸 爬虫引擎（4 级 fallback）

为什么是这 4 个？引擎不在多，在精、互补。日常爬取只有 httpx 在跑，不启动浏览器。

层级 引擎 解决什么 装依赖
1 httpx 最快路径：trending 是 SSR，多数直接命中 pip install httpx
2 cloudscraper Cloudflare challenge 中间页 pip install cloudscraper
3 playwright_stealth JS 渲染 / 严格指纹检测 pip install playwright playwright-stealth && playwright install chromium
4 jina 本地 IP 被封时换出口（公开免费） 无（firecrawl CLI 自带）

质量门：每级结果过三层判据才算数（长度 ≥ 500 字符 / 不含 bot-check 特征 / trending 页 ≥5 个 <article class="Box-row">），不过门自动升级下一级。

引擎白名单在 config.toml [orchestrator].priority —— 不在列表里的引擎永不运行（即使装了也禁用）。想用付费的 firecrawl 替代 jina？加进 priority 数组即可。

更多 10 个停用适配器（firecrawl / crawl4ai / playwright / nodriver / crawlee / scrapy / agent_reach / trafilatura / beautifulsoup / drissionpage）能力与上述 4 级重叠，代码保留着不再调度。

➕ 加新数据源

加一个 fetcher = 三个改动，~50 行：

  1. 写 fetcher sources/<name>.py：

    def fetch_<name>(max_items: int = 30) -> list:
    return [{
        "name": "owner/repo", "url": "...", "desc": "...",
        "stars": 100, "lang": "Python", "topics": ["ai"],
        "source": "<name>",
    }, ...]

  2. 注册到 radar_pkg/core.py 的 CATEGORIES：

    {"id": "<name>", "name": "...", "desc": "...", "queries": [], "source": "<name>"}

  3. 挂到 radar_pkg/crawl.py:_crawl_inner 的 dispatch：

    elif src == "<name>":
    repos = fetch_<name>(max_items=30)

后续的翻译、upsert、hot_now 自动复用。改主题分类关键词看 core.py:CATEGORY_TOPIC_HINTS。

🛟 故障排查

/api/data 返 502

原因：终端/浏览器走了 HTTP 代理，代理拦截 localhost。

解决：

# 终端测试绕过代理
curl --noproxy '*' http://127.0.0.1:8765/api/data
# 浏览器：用 http://127.0.0.1:8765（不走代理）而不是 localhost

Vite 报 Address already in use

lsof -ti :8765 | xargs kill -9
lsof -ti :5174 | xargs kill -9   # 5174 是 lodestone vite 端口
cd frontend && npm run vite-only

crawl 一直卡在 rate-limit hit

原因：GitHub Search API 30 req/min 限流。

解决：等 60s 自动恢复。./radar.py crawl 内置退避。日志在 data/crawl.log。

gh: API rate limit exceeded for <IP>

原因：gh 的登录 token 过期了；未认证按 IP 限流（10 次/分钟）。

解决（选一）：

# 方式 1：交互式重新登录
gh auth login -h github.com

# 方式 2：写到 .env（gh CLI 原生读取 GH_TOKEN）
echo 'GH_TOKEN=ghp_xxxx' >> .env

token 有效时搜索走 GraphQL 批量（204 个 query 约 3 分钟）；失效时降级 REST → HTML 阶梯兜底，更慢（10 分钟+）但功能不丢。

description 字段是英文

HF API 对 Spaces/Models 不返回 desc。refresh_snapshot.py 用 repo name 合成 placeholder（"Owner/RepoName — AI / ML project"），自动翻译。

MCP Server 标记而不是具体语言

MCP Registry 服务不是 GitHub repo，没 language 字段。/api/stats 自动过滤它，/api/data 卡片仍显示 "MCP Server"。

macOS Python 报 SSL: CERTIFICATE_VERIFY_FAILED

# 方案 1：装证书
/Applications/Python\ 3.13/Install\ Certificates.command

# 方案 2：装 certifi（更省事）
pip install --upgrade certifi

所有 scraper 已默认 urllib → curl 回退，应该自动绕过。

卡片没显示「安装」按钮

检查 repo.is_skill：

curl --noproxy '*' -s http://127.0.0.1:8765/api/data | python3 -c "
import json, sys
d = json.load(sys.stdin)
for r in d['hot_now'][:5]:
    print(f\"{r['name']:<35} is_skill={r.get('is_skill')}\")
"

is_skill=False 表示仓库根没有 SKILL.md，按设计不显示装按钮 —— 这是正确的（不是所有 GitHub 项目都能装为 skill）。
